
# Content Crafter AI

This Python-based application streamlines AI-powered content creation by integrating multiple APIs. It retrieves article titles from Google Sheets via the Google Sheets API, selects the most relevant titles, and generates new articles using OpenAI's GPT-based text generation (OpenAI API). It then creates AI-generated images using GPT-4 Vision capabilities and uploads the complete post—text and image—directly to WordPress using the WordPress REST API.
